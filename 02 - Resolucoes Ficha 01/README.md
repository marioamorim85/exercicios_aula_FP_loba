# Resoluções — Ficha de Trabalho 01 (Fundamentos de Programação)

Resoluções, exercício a exercício, da Ficha de Trabalho 01 (Sessão 1) e das práticas do deck.

**`0 - Diagnostico (respostas orientadoras).md`** — guia do formador para as 6 perguntas de diagnóstico do slide 5 (respostas-modelo e sinais a observar; o diagnóstico não conta para a nota).

## Como usar
- Ficheiros **.fprg** abrem no **Flowgorithm** (Ficheiro → Abrir). Carrega em **Executar (▶)** para ver correr.
- Ficheiros **.txt** têm a resolução em linguagem natural ou pseudocódigo.
- São **uma** solução possível — há sempre variações válidas.

## Estrutura
```
Grupo1_LinguagemNatural/   1.1 a 1.4  (.txt — passos em português)
Grupo2_Flowgorithm/        2.1 a 2.5  (.fprg — abrem e correm no Flowgorithm)
Grupo3_Pseudocodigo/       3.1 a 3.3  (.fprg + .txt)
```
