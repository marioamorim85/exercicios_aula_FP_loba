# Resoluções — Ficha de Trabalho 03 (Ciclos e Arrays)

Uma solução possível para cada exercício da Sessão 3.

- **.fprg** abrem no Flowgorithm (Ficheiro → Abrir) e correm com Executar (▶).

```
Grupo1_Pseudocodigo/   1.1 a 1.2  (.txt)
Grupo2_Flowgorithm/    2.1 a 2.5  (.fprg — Para, Enquanto, Faça, arrays)
Grupo3_Desafio/        3.1        (.fprg — mini CRM integrador)
```
